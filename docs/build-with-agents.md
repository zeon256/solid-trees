# Build with agents (/docs/build-with-agents)

## Plain-text docs [#plain-text-docs]

Our documentation is also available in condensed Markdown text, available in two
versions:

- [llms.txt](/llms.txt) is a short index of the pages
- [llms-full.txt](/llms-full.txt) is the everything in the docs — prose, API
  lists, and code examples

Every page is also available on its own: append `.md` to its URL, or use the
"Copy Markdown" button under the page title.

Copy and paste as needed, or provide the URLs to your agent.
