Overview

Guide-first documentation for solid-trees, covering the Solid API, prepared input, styling, icons, Git status, and large trees.

solid-trees uses one path-first model. It is a SolidJS 2 port of @pierre/trees: the model layer is vendored from upstream, and the view is a native Solid rewrite rendered into the light DOM. Selection, focus, search, rename, drag and drop, Git status, and row annotations all use canonical paths.

These docs are guide-first. First, create a model and render it. Next, shape the tree data before it reaches the UI. Then add search, item actions, styling, icons, or row signals when you need them.
